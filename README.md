# MAP-STROKE

We developed a novel stroke triage algorithm using jointly fit Bayesian models, trained on over 10,000 patient records from clinical trials and real-world data. The algorithm incorporates transport times, locations, and hospital capabilities to optimize prehospital triage decisions.

The repository has the main functions and simulated data sets used in the MAP-STROKE project.

1. _**Data**_: query and input datasets of synthetic stroke events.
